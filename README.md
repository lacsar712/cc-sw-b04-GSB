## 过滤台（服务端可保存方案）

顶栏「过滤台」提供灯种前缀过滤，过滤在服务端执行（不在浏览器藏行）：

- 前缀框：输入前缀点「服务端查询」（或回车）即服务端重查；空前缀返回全部行。
- 命名方案：校准员与巡检均可保存/切换/变动方案；切换方案立即按其前缀服务端重查。
- 方案说明随方案一起保存。
- 变更履历：方案的新增、变动、删除均写入 `filter_history`，删除方案后履历仍留痕。
- 删除权限：方案创建者本人可删；校准员可删任意方案；巡检不可删他人方案（前后端均拦截）。

接口：`GET /api/jobs?prefix=`、`GET/POST /api/filter-schemes`、
`POST /api/filter-schemes/{id}`（变动）、`POST /api/filter-schemes/{id}/delete`、
`GET /api/filter-history`。

验收场景：

1. 投氦灯、汞灯各一条后，在过滤台前缀填「氦」、方案名填「方案甲」保存，结果表只见氦灯行。
2. 清空前缀后查询，氦灯与汞灯两行都在。
3. 删除「方案甲」后，变更履历中仍保留该方案的新增/删除记录。
4. inspector 登录后，删除他人创建的方案按钮被禁用，接口直接调用返回 403。
